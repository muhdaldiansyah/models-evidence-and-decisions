# Chapter 4 — Cold-Transfer Rubric

Open this file only **after** completing the transfer response.

Score each dimension from **0 to 2**. Use the dimensions diagnostically; there is **no validated aggregate cut score**.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Two processes | Only the process being asked about is described | Both mentioned, but the recording process is a sentence | Both described substantively, and separately |
| Institutional purpose | Not identified, or given as "record keeping" | A purpose is named | The purpose is named **and** its blind spot is derived from it |
| Stages | Fewer than three, or three that are really one | Three named | Three or more named, each with who decided and what they were optimising |
| Absence | Not identified, or a *missing value* offered instead of an absent unit | A category identified | Identified, **and** why nothing in the data reveals it is explained |
| Relationship to the quantity | Not addressed | Asserted that the data is biased | Stated whether being recorded is related to the quantity, **and in which direction** |
| Why more would not help | Not addressed, or "more data always helps" | Asserted that more would not help | Explained by reference to which stage more records would and would not change |
| Out-of-scope item | Not identified, or the wrong item chosen | Correct item identified | Correct item identified **and** the difference in kind explained |
| Register kept clean | Institution treated as negligent or dishonest | Neutral | Each decision shown to be sensible for whoever made it |

The last dimension is not politeness. A provenance analysis that concludes people were careless has usually stopped one question early, and it will miss the cases where everyone behaved well and the data is still unusable.

Regardless of any total, major category errors include:

- describing data-quality problems (nulls, duplicates, formats) instead of provenance;
- proposing more of the same records as the remedy;
- treating an absent category as a missing value;
- concluding the dataset is "biased" without saying for which quantity;
- inventing a fact the form did not supply;
- placing the Chapter 15 item alongside the others as though it were the same kind of thing;
- answering the committee's or partnership's question anyway, using the register.

That last one is worth its own note. Both forms describe a dataset that cannot answer the question it is being used for. The correct output is not a better ranking or a better trend — it is a statement of what the register can and cannot support, and what would have to change.
