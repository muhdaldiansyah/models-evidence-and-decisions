Copy this file per participant per chapter. Name the copy `pilot-ch<NN>-p<NN>.md` and keep it outside the repository if it contains anything identifying.

**For Chapter 1, use [`../chapters/01-decisions-questions/pilot-data-capture.md`](../chapters/01-decisions-questions/pilot-data-capture.md) instead** — it is the fuller instance and Chapter 1's gates are written against it.

**Blank means not captured. It does not mean absent, zero, or fine.** If something was not observed, write `not captured` rather than leaving the line empty.
